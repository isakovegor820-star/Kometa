## 0. Резюме в 10 строк

1. Продукт: **Telegram-бот продаёт подписку на VPN**, канал — витрина, контент, поддержка и удержание.
2. Аудитория: **русскоязычные пользователи в РФ**, основная боль — блокировки сайтов и сервисов, нестабильность мобильной сети.
3. Технология: **готовая панель управления VPN (3x-ui → при росте Remnawave) + собственный бот на Python (aiogram 3) + собственная ссылка-подписка**.
4. Протоколы: **VLESS + Reality** (основной) и **AmneziaWG** (резервный, UDP) — два независимых канала на ноду.
5. Тарифы: 1 мес — 199 ₽, 3 мес — 499 ₽, 6 мес — 890 ₽, 12 мес — 1 590 ₽. Пробный доступ 3 дня / 1 устройство / 10 ГБ.
6. В подписке: **безлимитный трафик, до 3 устройств**, 2 локации на старте (Германия, Нидерланды).
7. Приём денег: **ручные переводы СБП + крипта (CryptoBot)**, далее Telegram Stars. Российский эквайринг для VPN закрыт — это не наша ошибка, это рынок.
8. **Юридическое ограничение №1: реклама средств обхода блокировок в РФ запрещена** (штраф гражданину 50–80 тыс. ₽). Продвижение — только через свой канал, сарафан и рефералку, без слова «обход» в рекламных креативах.
9. **Юридическое ограничение №2: приём платежей оформляется на совершеннолетнего** (родитель или друг 18+) — иначе нет легального способа принимать фиат.
10. Бюджет 10 000 ₽ разово: 2 ноды на 3 месяца + домен + буфер ≈ 6 500 ₽, остаток — резерв.

## 1. Цели и метрики

### 1.1 Цель проекта
Запустить работающий сервис доступа к интернету по подписке с приёмом платежей внутри Telegram и выйти на первую выручку в течение 3 месяцев.

### 1.2 Метрики успеха (проверяем через 90 дней)

| Метрика | Цель | Как считаем |
|---|---|---|
| Платящих подписчиков | 20–50 | активные подписки в БД |
| Выручка | 5 000–15 000 ₽/мес | сумма успешных платежей |
| Конверсия trial → оплата | ≥ 20 % | оплатившие / взявшие триал |
| Отток (churn) | ≤ 15 %/мес | не продлившие из числа истёкших |
| Доступность сервиса | ≥ 99 % часов в сутках | Uptime Kuma + healthcheck |
| Окупаемость инфраструктуры | с 8–10 платящих | выручка ≥ стоимость нод |

### 1.3 Что НЕ входит в MVP
- Свой VPN-клиент под iOS/Android (дорого, долго, не нужно).
- Юрлицо, договоры с компаниями, SLA.
- Более 2 локаций, более 100 пользователей, партнёрская программа для инфлюенсеров.
- Полноценный веб-личный кабинет (всё живёт в Telegram).

## 2. Аудитория, позиционирование, юридическая рамка

### 2.1 Портрет клиента
- 18–40 лет, Россия, мобильный + ноутбук, пользуется Telegram.
- Хочет: YouTube/Instagram/зарубежные сервисы без тормозов; стабильный доступ; простую настройку «в 2 клика».
- Платит неохотно и понемногу, но готов платить за то, что **работает и не отваливается**.
- Не хочет: разбираться в конфигах, читать 20 шагов инструкции.

### 2.2 Позиционирование (важно из-за запрета рекламы)
Формулировки для канала и бота: **«сервис защищённого подключения»**, «стабильный доступ к вашим сервисам», «приватность и скорость».
**Запрещено** в рекламных материалах (и вообще в РФ-каналах): «обход блокировок», «VPN для обхода», «доступ к запрещённым сайтам», «обход РКН».

Обоснование: ч. 10.8 ст. 5 ФЗ-38 «О рекламе» + ч. 18 ст. 14.3 КоАП РФ — реклама средств обхода блокировок карается штрафом **50–80 тыс. ₽ для граждан**, 80–150 тыс. ₽ для должностных лиц, 200–500 тыс. ₽ для юрлиц. Так как реклама будет идти от имени плательщика-физлица, риск на нём.

### 2.3 Ключевые юридические ограничения и как мы их учитываем

| Ограничение | Что это значит | Что делаем |
|---|---|---|
| Запрет рекламы средств обхода блокировок | Нельзя покупать посевы/Telegram Ads с формулировкой про обход | Растим свой канал, рефералку, сарафан; реклама — только «защищённое подключение» |
| Российский эквайринг VPN не обслуживает | ЮKassa/CloudPayments/банки отказывают («анонимайзеры» в офертах) | Деньги принимаем через СБП-переводы, крипту, Telegram Stars |
| Приём платежей требует дееспособности | Основателю 15 лет — самозанятость/ИП недоступны | Все платежи оформляются на совершеннолетнего (родитель или друг 18+), обязательно с его согласия |
| 152-ФЗ о персональных данных | Нельзя собирать лишние данные | Храним только Telegram ID, username, даты и суммы. Никаких email/телефонов/паспортов |
| НПД (самозанятость) и перепродажа | НПД не подходит для перепродажи товаров; по услугам доступа — серая зона | Консультация с налоговиком до масштабирования; на старте — минимальные обороты |
| Блокировка бота/домена в РФ | Возможна | Держим резервный домен, бот работает и по прямой ссылке, аудиторию удерживаем в канале + резервном канале |

### 2.4 Честно про «обходы во время БПЛА»
Если мобильный интернет в регионе **отключают полностью** — обойти это технически невозможно: нет канала связи, VPN работает только поверх интернета. Что мы можем:
- работать при **частичных** ограничениях (блокировки сайтов, замедление, фильтрация по SNI);
- давать **резервные протоколы и порты** (Reality по 443/TCP + AmneziaWG по UDP-порту), чтобы выживать при блокировке одного из них;
- иметь **2+ ноды в разных странах/подсетях**, чтобы блокировка одной не убивала сервис;
- держать **инструкцию «что делать, если не работает»** в боте (переключение локации/протокола в один клик).
Обещать «работает при выключенном интернете» — нельзя, это ложь и потеря клиентов.

## 3. Продукт: пользовательские сценарии

### 3.1 Первый контакт (2 клика до работающего доступа)
1. Пользователь открывает бота (`/start`).
2. Видит: «3 дня бесплатно — 1 устройство, 10 ГБ» → кнопка **«Попробовать бесплатно»**.
3. Бот создаёт аккаунт в панели, выдаёт **ссылку-подписку** и кнопку **«Как подключить»** (пошагово для Android/iOS/Windows, с ссылками на v2rayNG / Hiddify / Happ / sing-box).
4. Через 3 дня бот напоминает: «Пробный доступ закончился — продлить за 199 ₽?»

### 3.2 Покупка подписки
1. Меню **«Тарифы»** → выбор срока (1/3/6/12 мес).
2. Выбор способа оплаты (СБП-перевод / крипта / Stars).
3. Оплата → бот автоматически продлевает подписку, присылает чек-подтверждение и обновлённую ссылку.
4. При ручной оплате — кнопка «Я оплатил» → админ подтверждает → доступ выдаётся (цель: < 15 минут в рабочее время).

### 3.3 Моя подписка
Экран с: статусом, датой окончания, остатком трафика (если лимит), числом устройств, ссылкой-подпиской, кнопкой «Докупить/продлить», «Сменить локацию», «Инструкция», «Поддержка».

### 3.4 Продление
- За 3 дня и за 1 день — напоминание в боте.
- После истечения — доступ отключается автоматически (панель блокирует пользователя), данные сохраняются 30 дней.
- Продление в 1 клик (тариф запоминается).

### 3.5 Реферальная программа (этап 2)
- У каждого пользователя своя ссылка `t.me/<bot>?start=ref_<code>`.
- Приглашённый оплатил → **+7 дней** пригласившему и **+3 дня** приглашённому.
- Защита от накрутки: бонус только после первой реальной оплаты, не более 10 наград/мес.

### 3.6 Канал
- Витрина: что за сервис, тарифы, отзывы, статус сервиса (аптайм), инструкции, анонсы.
- Контент-план на 4 недели (см. `docs/ПРОДАЖИ.md`): 3 поста/неделю — статус/новости, польза (как смотреть YouTube без тормозов), соцдоказательство.
- Канал — «страховка» на случай блокировки бота: там всегда актуальная ссылка.

## 4. Тарифы, лимиты, пробный доступ

| Тариф | Цена | Цена за месяц | Устройств | Трафик |
|---|---|---|---|---|
| Пробный | 0 ₽ (3 дня) | — | 1 | 10 ГБ |
| 1 месяц | 199 ₽ | 199 ₽ | 3 | безлимит |
| 3 месяца | 499 ₽ | 166 ₽ | 3 | безлимит |
| 6 месяцев | 890 ₽ | 148 ₽ | 3 | безлимит |
| 12 месяцев | 1 590 ₽ | 132 ₽ | 3 | безлимит |

- Все цены и лимиты **хранятся в БД**, а не в коде — меняются через админку без перезапуска.
- «Устройство» = одновременное подключение (в панели — лимит IP/сессий на пользователя).
- Защита от шеринга: контроль числа одновременных IP, авто-предупреждение при превышении, ручная блокировка админом.
- Экономика: 30 платящих × ~250 ₽ ≈ **7 500 ₽/мес** выручки при затратах на 2 ноды ~700–1 100 ₽/мес.

## 5. Платежи

### 5.1 Что мы выяснили (факты)
- **Российский эквайринг для VPN практически закрыт**: в офертах банков прямые запреты («анонимайзеры»); крупные платёжные системы перестали обслуживать VPN-провайдеров.
- **Telegram Stars** — штатный путь внутри Telegram, но экономически дорогой: ставка выплаты разработчику $0,013/Star, заморозка до 21 дня, вывод только в TON через Fragment, минимум 1 000 ⭐.
- **CryptoBot (Crypto Pay)**: 0 % внутри Telegram, вывод ~1 USDT (TRC20) / 0,05 TON, кастодиальный.
- **СБП-перевод на карту** — единственный способ, понятный 100 % РФ-аудитории, но ручной и требует карты/счёта совершеннолетнего.

### 5.2 Решение для MVP
Архитектурно делаем **провайдера платежей сменным** (интерфейс `PaymentProvider`), включаем три:

| Приоритет | Способ | Плюсы | Минусы | Статус |
|---|---|---|---|---|
| 1 | СБП/перевод на карту + подтверждение админом | Работает всегда, понимает каждый | Руками, задержка до 15 мин | MVP |
| 2 | Крипта (CryptoBot: USDT/TON) | Автоматически, 0 % внутри | Часть аудитории не умеет | MVP |
| 3 | Telegram Stars | Всё внутри Telegram, автовыдача | Дорого (−15…35 %), вывод TON | Этап 2 |
| — | РФ-эквайринг | Удобно | Откажут | Не рассматриваем |

### 5.3 Оформление приёма денег (возраст)
Основателю 15 лет → самозанятость/ИП недоступны, банковский счёт и договор с платёжным сервисом — тоже.
**Вариант, который рекомендую:** оформление на **родителя** (самозанятость, НПД 6 %), он же владелец карты/кошелька для приёма. Основатель делает продукт, технологию и развитие, взрослый — платёжную и юридическую часть.
**Вариант «на друга 18+»**: возможен, но друг становится фактическим получателем дохода: он платит налог, отвечает перед банком и налоговой, и именно ему прилетит штраф, если будет нарушена реклама. Обязательно письменно договориться о разделе и о том, кто что делает. Не рекомендую как основной путь, но он рабочий.
**Что нельзя:** принимать деньги на карту 15-летнего (нет дееспособности, счёт могут заблокировать, сделки оспоримы).

### 5.4 Схема выдачи доступа после оплаты
```
Пользователь → бот: выбрал тариф
   → бот создаёт заказ (status=pending) со сроком жизни 30 минут
   → оплата (СБП вручную / крипта авто / Stars)
   → подтверждение (админ или вебхук)
   → сервис подписок: продлевает срок в БД + создаёт/продлевает пользователя в панели
   → бот: «Оплата получена, подписка активна до <дата>» + ссылка-подписка
```
Идемпотентность: платёж обрабатывается по уникальному `external_id`, повторный вебхук не продлевает дважды.

### 6.2 Выбор компонентов и обоснование

| Слой | Выбор | Почему | Альтернативы |
|---|---|---|---|
| Бот | **Python 3.12 + aiogram 3**, long polling | Не нужен домен и HTTPS для запуска — стартуем сегодня; простая логика платежей и планировщик | Telebot (проще, но слабее), Node/grammY |
| БД | **SQLite** на старте → **PostgreSQL** при >100 юзеров | Ноль настройки, файл бэкапится одной командой; SQLAlchemy позволяет перейти без переписывания | Postgres сразу (сложнее деплой) |
| Панель | **3x-ui** | Активный проект (релиз 03.10.2026), поддерживает Reality и AmneziaWG, простой API, ставится одной командой | Remnawave (мощнее, но требует 2+ ГБ RAM на панель), Marzban (заброшен) |
| Протоколы | **VLESS+Reality** + **AmneziaWG** | Reality даёт ~0,4–0,6 Гбит/с на 1 vCPU; AmneziaWG в бенчмарках быстрее и устойчивее к DPI; два протокола = выживаемость | Hysteria2 (QUIC, режут), Shadowsocks (старее), OpenVPN (медленно) |
| Клиенты (не наши) | v2rayNG, Hiddify, Happ, sing-box | Пользователь не ставит наш софт, а импортирует ссылку-подписку | — |
| Планировщик | APScheduler внутри бота | Не нужен отдельный сервис | Celery (избыточно) |
| Мониторинг | Uptime Kuma + healthcheck-скрипт + алерты в админ-чат | Дёшево и достаточно | Prometheus/Grafana (избыточно) |
| Деплой | Docker Compose на ноде + отдельная нода под панель | Воспроизводимо, переносимо | Ручная установка (хрупко) |

### 6.3 Почему своя ссылка-подписка
Панель умеет отдавать подписку одного пользователя, но нам нужно:
- одна ссылка на все локации (клиент сам выберет быструю или переключится при блокировке);
- наши метаданные: имя профиля, интервал обновления, срок действия;
- независимость от панели: сменим панель — ссылка у пользователя не изменится.
Реализация: `GET /sub/<token>` на нашем бэкенде → собирает конфиги из панели(ей) → отдаёт base64-список `vless://…` + `amneziawg://…` с заголовками `profile-title`, `profile-update-interval`, `subscription-userinfo`.

### 6.4 Устойчивость к блокировкам (2026)
- ТСПУ перешёл к **поведенческому анализу** (TLS-отпечатки, число соединений, подсети), поэтому «неубиваемых» протоколов нет — выигрывает тот, кто быстро адаптируется.
- Меры: два протокола на ноду; резервные порты (443/TCP + UDP); 2 ноды в разных странах и разных подсетях; возможность быстро поднять третью ноду; мониторинг «подключено, но не работает» (кроме аптайма — проверка реальной доступности через ноду); готовые инструкции по переключению локации в 1 клик.

## 8. Бот: экраны и функции

### 8.2 Админские (только для tg_id из конфига)
- `/stats` — юзеры, триалы, платящие, выручка за день/неделю/месяц, конверсия.
- `/user <tg_id>` — карточка: подписка, платежи, устройства, действия.
- Выдать/продлить/заблокировать доступ вручную, вернуть деньги (в БД + панель).
- Подтвердить ручной платёж (из очереди «ожидают подтверждения»).
- Рассылка по сегментам (активные / истёкшие / триалы) с подтверждением.
- `/nodes` — статус нод, трафик, число пользователей.
- Автоалерты: нода недоступна, ошибка API панели, всплеск ошибок, подозрение на шеринг.

### 8.3 Тексты
Все тексты — в одном модуле (`texts.py`), без хардкода в хендлерах: их правят без программиста. Тон: спокойный, без обещаний «обхода блокировок» — только «стабильное защищённое подключение».

### 9.3 Роли серверов
- **Нода A (DE)**: панель 3x-ui + VPN-инбаунды. Минимум 1 vCPU / 1 ГБ / 10–30 ГБ, порт 1 Гбит/с.
- **Нода B (NL)**: VPN-инбаунды, подключается к панели как дополнительный сервер (или вторая панель на этапе MVP, объединяем своей ссылкой-подпиской).
- Бот может жить на ноде A (нагрузка копеечная), при росте — вынести на отдельный мелкий VPS.

### 9.4 Деплой (целевое состояние)
```
docker compose up -d
  ├─ bot        (наш код)
  ├─ db         (postgres; на MVP — SQLite-файл с бэкапом)
  └─ panel      (3x-ui)
```
- `.env` — все секреты (токен бота, токен панели, реквизиты, id админов).
- Обновление: `git pull && docker compose up -d --build`.
- Бэкап: ежедневный дамп БД + конфиг панели, хранение 14 дней, выгрузка в отдельное место (не на ту же ноду).
- Откат: предыдущий образ + дамп БД (описано в `docs/ЗАПУСК.md`).

### 9.5 Безопасность
- Доступ к панели — только по токену/паролю, порт панели не светим в публичку без нужды, вход по SSH — только ключом, root-логин по паролю выключен.
- В боте — антифлуд (не более N запросов/мин), проверка подписки на канал при необходимости.
- Секреты не в git: `.env` в `.gitignore`, ротация токена бота при утечке.
- Логи без персональных данных.

## 14. Критерии приёмки MVP

1. Пользователь в боте получает пробный доступ за ≤ 2 клика и подключается по инструкции к реальной ноде.
2. Оплата проходит минимум одним способом end-to-end, подписка автоматически продлевается.
3. Истёкшая подписка автоматически отключается в панели, напоминания приходят за 3 и 1 день.
4. Админ видит статистику и может выдать/продлить/заблокировать доступ и подтвердить платёж.
5. Сервис разворачивается на чистой ноде по инструкции за ≤ 30 минут.
6. Бэкап БД создаётся автоматически и восстанавливается по инструкции.
7. Ссылка-подписка работает минимум в двух клиентах (v2rayNG + Hiddify) и содержит ≥ 1 локацию.
8. В коде нет секретов, есть `.env.example`, README с запуском, тесты на подписочную логику и платежи.
