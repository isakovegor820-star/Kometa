Как заходить
{% if local_only %} панель открыта только с localhost — вход через SSH-туннель: ssh -L 8090:127.0.0.1:8090 root@IP, дальше http://127.0.0.1:8090/admin. Если панель вынесена в интернет, ставь её за HTTPS и включай ADMIN_LOCAL_ONLY=false осознанно. {% else %} панель открыта по сети (ADMIN_LOCAL_ONLY=false) — держи её только за HTTPS: без шифрования пароль и сессия видны тому, кто стоит между тобой и сервером. {% endif %}
Резервный вход
{% if env_password_set %} пароль владельца из ADMIN_PANEL_PASSWORD работает всегда, даже если учётные записи потеряны или все выключены. Держи его в менеджере паролей и меняй после смены команды. {% else %} ADMIN_PANEL_PASSWORD не задан — резервного входа нет. Если потеряешь доступ к учётным записям, вернуть панель можно будет только правкой в базе. {% endif %}
Срок сессии
сессия живёт {{ session_hours }} ч (ADMIN_SESSION_HOURS), потом нужен повторный вход. Общий компьютер — выходи из панели кнопкой внизу меню.
Пароли
хранятся только хэшем (PBKDF2-HMAC-SHA256), в журнал не пишутся. Сброшенный пароль показывается один раз — передай человеку лично и попроси сменить.
