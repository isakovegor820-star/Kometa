# Запуск канала: описание бота, оформление канала, первый пост

Готовые к копированию тексты. Лимиты соблюдены: описание бота ≤ 512 знаков, «о боте» ≤ 120,
описание канала ≤ 255. Юридическая рамка — из [ПРОДАЖИ.md](ПРОДАЖИ.md): продаём качество связи
и приватность, а не «обход».

---

## 1. Бот в @BotFather

### 1.1 Что настроить

| Команда BotFather | Что вписываем |
|---|---|
| `/setname` | `Kometa` |
| `/setdescription` | текст из 1.2 |
| `/setabouttext` | текст из 1.3 |
| `/setuserpic` | `brand/avatar/kometa-avatar-512.png` |
| `/setcommands` | список из 1.4 |

### 1.2 Описание (`/setdescription`) — видно до нажатия «Старт»

```
Kometa — сервис защищённого подключения для телефона, ноутбука и ТВ.

• Стабильный доступ к вашим сервисам — без тормозов даже вечером
• Безлимитный трафик, до 3 устройств одновременно
• 2 локации: Германия и Нидерланды, переключение в один тап
• Настройка за 2 минуты: получаете ссылку-подписку и вставляете в приложение
• Оплата: СБП, крипта или Telegram Stars — от 199 ₽ в месяц

Первые 3 дня — бесплатно и без карты: проверьте скорость на своих сайтах и приложениях.
```

### 1.3 О боте (`/setabouttext`) — короткая строка в профиле

```
Защищённое подключение без тормозов: безлимит, до 3 устройств, 2 локации. Первые 3 дня бесплатно.
```

### 1.4 Команды (`/setcommands`)

Ставим только то, что реально обрабатывается в коде (`/start`, `/menu`, `/support`):

```
start - Открыть меню
menu - Главное меню
support - Написать в поддержку
```

## 2. Канал

### 2.1 Название и описание

**Название:** `Kometa | защищённое подключение`

**Описание (≤ 255):**

```
Сервис защищённого подключения Kometa. Новости, статус сервиса, инструкции и поддержка.
Безлимит, до 3 устройств, 2 локации. Первые 3 дня бесплатно, тарифы от 199 ₽.
Подключение и оплата — в боте: t.me/ВАШ_БОТ
```

### 2.2 Оформление

- **Аватар канала** — `brand/avatar/kometa-avatar-1024.png` (тот же знак, что у бота: узнаваемость).
- **Закреплённое сообщение** — первый пост из раздела 3 (в Telegram: «Закрепить» без уведомления).
- **Ссылка на бота** — в описании канала и в закрепе. Канал — страховка на случай блокировки бота
  (см. ТЗ, риск «Блокировка бота/домена в РФ»).
- **Комментарии** — включить: живые вопросы в комментариях работают лучше, чем посты в пустоту.

## 3. Первый пост

Публикуется вручную от своего аккаунта. Кнопки у ручного поста не будет — поэтому ссылка на бота
стоит отдельной строкой в тексте (Telegram сам сделает её кликабельной).

**Текст (копировать целиком):**

```
🚀 Kometa — стабильное подключение без тормозов

Запустили сервис защищённого подключения для телефона, ноутбука и ТВ. Настраивается за 2 минуты
и дальше работает в фоне: включил и забыл.

Что входит:
• Безлимитный трафик, до 3 устройств одновременно
• 2 локации: Германия и Нидерланды — переключение в один тап
• Одна постоянная ссылка-подписка: при продлении ничего перенастраивать не нужно
• Поддержка прямо в Telegram — отвечаем за пару минут

Тарифы:
• 1 месяц — 199 ₽
• 3 месяца — 499 ₽ (166 ₽ в месяц)
• 6 месяцев — 890 ₽ (148 ₽ в месяц)
• 12 месяцев — 1 590 ₽ (132 ₽ в месяц)

Оплата: перевод по СБП, крипта или Telegram Stars — как удобнее.

Как попробовать:
1. Открыть бота: t.me/ВАШ_БОТ
2. Нажать «🎁 Попробовать бесплатно» — 3 дня, 1 устройство, 10 ГБ
3. Вставить ссылку в приложение по инструкции из бота — и подключиться

Карта не нужна, автосписаний нет: пробный доступ даётся один раз на аккаунт.

Что будет в канале: инструкции по настройке под Android, iPhone и Windows, статус сервиса
и аптайм, замеры скорости, ответы на частые вопросы. Если что-то не работает — сразу пишите
в поддержку @ВАША_ПОДДЕРЖКА, разберёмся за несколько минут.
```

### 3.1 Если пост публикует бот (тогда можно добавить кнопку)

Формат для отправки через Bot API (`parse_mode=HTML`) — с кнопкой «Попробовать 3 дня» на
`https://t.me/ВАШ_БОТ`. Отличия от ручного текста — только разметка и кнопка:

```html
🚀 <b>Kometa — стабильное подключение без тормозов</b>

Запустили сервис защищённого подключения для телефона, ноутбука и ТВ.
Настраивается за 2 минуты и дальше работает в фоне.

<b>Что входит:</b>
• Безлимитный трафик, до 3 устройств одновременно
• 2 локации: Германия и Нидерланды
• Одна постоянная ссылка-подписка — при продлении менять ничего не нужно
• Поддержка прямо в Telegram

<b>Тарифы:</b> 199 ₽ / 499 ₽ / 890 ₽ / 1 590 ₽ — от 132 ₽ в месяц на годовом
<b>Оплата:</b> СБП, крипта, Telegram Stars

<b>Как попробовать:</b> нажмите кнопку ниже — 3 дня бесплатно, без карты.
```

Кнопка: `🎁 Попробовать 3 дня` → URL `https://t.me/ВАШ_БОТ`.
Прямого перехода в триал (`?start=trial`) бот пока не умеет — сейчас поддерживается только
`?start=ref_<код>`. Если нужен один тап до пробного доступа, это правка на 10 строк в
`app/bot/handlers/start.py` — скажите, добавлю.

## 4. Посты 2 и 3 (чтобы к запуску было 6 постов, как в плане)

**Пост 2 — через день после первого: «Как подключить за 2 минуты»**
Скриншоты шагов + текст из `texts.HOWTO`: установить приложение (Android: v2rayNG / Hiddify;
iPhone: Streisand / Happ), вставить ссылку-подписку, обновить и подключиться.
Финал: «Не получилось — напишите в поддержку, поможем за пару минут».

**Пост 3 — ещё через день: «Статус сервиса»**
Сколько человек подключено, какие локации работают, аптайм за неделю, что починили.
Смысл — показать живой проект до первых продаж (см. `docs/ПРОДАЖИ.md`, неделя 1).

## 5. Памятка: чего в текстах быть не должно

| ❌ Нельзя | ✅ Вместо этого |
|---|---|
| «Обход блокировок», «обход РКН» | «Стабильное защищённое подключение» |
| «Доступ к запрещённым сайтам» | «Доступ к вашим сервисам без тормозов» |
| «Обойди блокировку YouTube» | «YouTube без лагов и рекламы» |
| «VPN для обхода» | «Личный VPN-профиль для телефона и ноутбука» |

Правило: в публичных текстах продаём качество связи и приватность. Прямее можно только
в личных переписках и внутри бота.
