# Подключение клиентов и приставки: что проверяем в поле

> **Дата:** 07.10.2026. **Зачем документ:** в подписке заявлена совместимость с десятком приложений,
> но проверена она только кодом (определение формата по User-Agent) — в поле нет. Здесь чек-лист,
> по которому это проверяется за один вечер, и готовые приёмы для ТВ, где обычный импорт ссылки не
> работает.

---

## 1. Что отдаёт наш сервер

| Формат | Кто получает | Что внутри |
|---|---|---|
| base64-список | Happ, v2rayNG, v2RayTun, Streisand, большинство «универсальных» клиентов | все профили, каналы видны метками в именах («· резерв», «· CDN») |
| Clash/Mihomo YAML | FlClashX, Koala Clash, Clash Verge, Stash, Mihomo | группы «Авто», «Резерв», «CDN», правила РФ → напрямую |
| sing-box JSON | sing-box, Hiddify, Karing, SFA/SFI | те же группы + `route.rules` (РФ и локальная сеть — напрямую) |
| `?format=plain` | отладка | то же, без кодирования |

Формат выбирается сам по заголовку приложения; принудительно — `?format=clash|singbox|base64`.
Точка замера задержки — наш `GET /ping` (204), адрес попадает в группы автоматически
(`SUBSCRIPTION_TEST_URL`, если нужен свой).

## 2. Чек-лист полевой проверки

Проверяем на **трёх** устройствах: Android, iPhone, Windows/macOS. Для каждого клиента — 6 пунктов.

| № | Что проверяем | Признак «ок» |
|---|---|---|
| 1 | Подписка добавилась по ссылке `/sub/<token>` | список локаций непустой |
| 2 | Имена локаций человеческие | видно страну, а не `DE-REALITY-firefox-u123` |
| 3 | Каналы различимы | есть профили с «· резерв» и «· CDN» (или группы «Резерв»/«CDN») |
| 4 | Пинг считается | у локаций есть задержка, а не «—»/«timeout» |
| 5 | Переключение работает | выбор профиля меняет выходной адрес (проверяем по IP) |
| 6 | РФ-сервисы идут напрямую | банк/Госуслуги открываются при включённом туннеле |

Клиенты, которые надо пройти целиком: **Happ, Hiddify, v2RayTun, v2rayNG, FLClashX, Koala Clash,
sing-box, Streisand**. Отдельно фиксируем: где нет групп (base64), где нет `xhttp` (Streisand),
где нет per-app (iOS).

Результат проверки пишем таблицей в `docs/` — она же становится ответом поддержки: «у тебя такое
приложение — делай так».

## 3. Android TV и приставки

Обычный путь «нажать ссылку в Telegram» на ТВ не работает: там нет мессенджера, а схемы `vless://`
не открываются. Рабочие варианты:

1. **Приложение на самой приставке (Android TV).** Поставить клиент с поддержкой Android TV
   (Hiddify, v2rayNG TV-сборки) и ввести ссылку подписки вручную: открыть на телефоне
   `/connect/<token>`, скопировать ссылку и ввести её на ТВ (или переслать себе в заметки).
2. **Через телефон как точку доступа.** Включить туннель на телефоне и раздать Wi-Fi — приставка
   ходит через него. Минус: телефон должен быть рядом и заряжен.
3. **На роутере.** Если роутер умеет клиента (OpenWrt/sing-box) — подписка ставится на нём, и
   приставка ничего не знает о туннеле. Самый удобный вариант для дома.

**Apple TV.** Клиентов с поддержкой tvOS мало, и наш аварийный уровень там не проверялся. Честный
ответ клиенту: на Apple TV работаем через роутер или через раздачу с iPhone; обещать «поставим
приложение на приставку» нельзя.

## 4. Что писать клиенту, если не работает

Порядок один и тот же для всех приложений:

1. Обновить подписку в приложении (потянуть список вниз).
2. Переключиться на профиль «резерв» или «CDN» — они для случаев, когда обычные локации не отвечают.
3. Включить и выключить авиарежим (10 секунд) — связь зависит от вышки.
4. Если не открывается совсем ничего — написать в поддержку: у нас есть дежурный канал.

Формулировки — из `app/bot/texts.py` (`RESERVE_HELP`); они проходят проверку
`tests/test_public_texts_clean.py`, менять их можно только вместе с ней.
