# Маркетинговая система Kometa: карта и календарь

> Точка входа. Здесь — всё, из чего состоит маркетинг сервиса: что внедрено, где это лежит,
> какие расчёты за этим стоят и в каком порядке запускать.
>
> Дата: 08.10.2026. Проверка состояния: `.venv/bin/python -m pytest` → **1403 зелёных**.

---

## 1. Из чего состоит система

```
                    ИСТОЧНИКИ ТРАФИКА
   ┌──────────────┬──────────────┬───────────────┬─────────────────┬──────────────┐
   │  Рефералка   │   Подарки    │   Конкурсы    │  Свой канал     │  Партнёры    │
   │  30 % / 14+14│  +25 %, год  │  220 ₽ фонд   │  контент + ЧС   │ссылка+выплата│
   └──────┬───────┴──────┬───────┴───────┬───────┴────────┬────────┴──────┬───────┘
          │              │               │                │               │

   ┌─────────────────────────────────────────────────────────────┐
   │  ВОРОНКА: /start → триал 3 дня → оплата → продление → друг  │
   │  метки источника (users.source) + событие на каждом шаге     │

   └─────────────────────────────────────────────────────────────┘

   │  ИЗМЕРЕНИЕ: source_stats() → CAC по каналам, LTV, отток      │
   │  потолок CAC = 218 ₽ (предел 327 ₽), LTV = 654 ₽             │
   └─────────────────────────────────────────────────────────────┘
```

## 2. Экономика: одна цифра, от которой всё считается

| Величина | Значение |
|---|---|
| Средний чек / на руки | 109 ₽ → **98 ₽** |
| LTV клиента при оттоке 15 % | **654 ₽** |
| **Потолок CAC** | **218 ₽** (осторожно) / **327 ₽** (предел) |
| Себестоимость обслуживания клиента | **10 ₽/мес** |
| Точка безубыточности | **4,7 клиента** |

Отсюда два следствия, которые определяют все решения:

1. **Призы и бонусы выдаём днями, а не деньгами.** Месяц подписки выглядит для клиента как 120 ₽,
   а кассе стоит 10 ₽. Разрыв в 12 раз — главный рычаг.
2. **Платные размещения не покупаем.** Не по цене, а по закону: ч. 18 ст. 14.3 КоАП —
   до 80 000 ₽ штрафа, и отвечает автор канала. Разбор: [МАРКЕТИНГ-ЭКОНОМИКА.md](МАРКЕТИНГ-ЭКОНОМИКА.md) §5а.


## 4. Воронка и целевые цифры

| Шаг | Что происходит | Цель | Где видно |
|---|---|---|---|
| 1. Первое касание | `/start` с меткой или без | — | `users.source` |
| 2. Пробный доступ | 3 дня, 1 устройство, без карты | 10+/нед | `/stats` → «На пробном» |
| 3. Оплата | перевод, звёзды, крипта | ≥ 20 % из триала | админка → заказы |
| 4. Продление | напоминания за 3 и 1 день | ≤ 15 % оттока в месяц | `/admin` → отток |
| 5. Приглашение | друг получает 30 %, клиент 14 дней | **15–25 % новых оплат** | `referrals` |
| 6. Подарок | покупка сертификата действующим клиентом | ≥ 1 из 5 покупок в месяц | `gift_stats()` |
| 7. Партнёр | внешний канал приводит аудиторию за процент | CAC канала ≤ 218 ₽ | `/admin/partners` |

**Каждый шаг считает код**, а не человек: `users.source` (откуда), `orders` (оплатил ли),
`referrals` (кого привёл), `events` (что происходило). CAC по каналам —
`app.services.attribution.source_stats()`.

| **Каждый месяц** | Конкурс отзывов и замеров: 3 месяца / 1 месяц / +7 дней | ~70–120 ₽ | там же |
| **Ноябрь** | Стартовое предложение: первый месяц 89 ₽ для первых 50 (промокод, лимит активаций) | 31 ₽ × 50 | [ПРОДАЖИ.md](ПРОДАЖИ.md) |
| **Декабрь** | Новогодний набор: 6 месяцев себе + сертификат в подарок | по факту подарков | [КОНКУРС-УСЛОВИЯ.md](КОНКУРС-УСЛОВИЯ.md), бот |
| **Январь** | «Продли год — цена не вырастет»: скидка на длинном тарифе, не на месячном | скидка на длинном тарифе | [ПРОДАЖИ.md](ПРОДАЖИ.md) |
| **Всплеск спроса** | Когда у людей массово «пропадает интернет» — усилить посты, но без обещаний и без платной рекламы | 0 ₽ | [КАНАЛ.md](КАНАЛ.md) |

**Ритм:** 3 поста в неделю в канале, один конкурс в месяц, каждый пост с кнопкой.

## 7. Красные линии (напоминание перед каждой акцией)

1. **Никакой платной рекламы** — ч. 18 ст. 14.3 КоАП, штраф до 80 000 ₽, отвечает автор канала.
2. **Никаких обещаний результата**: «работает везде», «1000 Мбит/с», «безлимит всегда» — не пишем.
3. **Публичные тексты — только про качество связи.** Перед публикацией:
   `.venv/bin/python -m pytest tests/test_public_texts_clean.py`.
4. **Призы — только дни подписки** и не дороже 4 000 ₽ на человека в год (иначе НДФЛ 35 % и уведомление ФНС).
5. **Конкурс, а не лотерея** — победитель по результату, участие бесплатное, условия опубликованы заранее.
6. **Не обещать срок подведения итогов, который не выдержим**: перенос даты убивает доверие
   сильнее, чем отсутствие конкурса.
