# Как опубликовать документы и показать их банку

Документы собраны в `docs/legal/` и уже готовы к копированию. Публикация занимает
5 минут — и делается одной командой: ссылка не меняется при обновлении текста,
поэтому её можно смело отдавать банку.

## 0. Автоматически (рекомендуется)

```bash
.venv/bin/python scripts/publish_legal.py
```

Скрипт сам заводит аккаунт Telegra.ph, публикует три страницы (политика,
соглашение, прайс) и прописывает ссылки в `.env`. Токен аккаунта сохраняется
в `.env` (`TELEGRAPH_ACCESS_TOKEN`), пути страниц — в `data/telegraph_pages.json`:
повторный запуск **обновляет те же страницы**, адреса не меняются.

```bash
.venv/bin/python scripts/publish_legal.py --dry-run   # проверить разметку без сети
.venv/bin/python scripts/publish_legal.py --only terms # обновить один документ
```

Опубликованные страницы (06.10.2026):

| Документ | Ссылка |
|---|---|
| Политика конфиденциальности | <https://telegra.ph/Politika-konfidencialnosti-10-06-38> |
| Пользовательское соглашение | <https://telegra.ph/Polzovatelskoe-soglashenie-10-06-26> |
| Цены и тарифы | <https://telegra.ph/Ceny-i-tarify-Kometa-10-06> |

После публикации перезапустите бота — кнопки в разделе «📄 Документы и цены»
станут ссылками на эти страницы.

## 0.1 Вручную (если нужно опубликовать под своим аккаунтом)

Ниже — тот же результат руками: Telegra.ph не требует регистрации, а ссылка
не меняется при редактировании.

---

## 1. Что публикуем

| Файл | Куда | Название страницы |
|---|---|---|
| `ПОЛИТИКА-КОНФИДЕНЦИАЛЬНОСТИ.md` | Telegra.ph | Политика конфиденциальности |
| `ПОЛЬЗОВАТЕЛЬСКОЕ-СОГЛАШЕНИЕ.md` | Telegra.ph | Пользовательское соглашение |
| `ЦЕНЫ-И-ТАРИФЫ.md` | Telegra.ph (или письмом в банк) | Цены и тарифы Kometa |

Перед публикацией убедитесь, что в текстах нет плейсхолдеров `[ИСПОЛНИТЕЛЬ]`,
`[ИНН]`, `@[ПОДДЕРЖКА]`, `@[БОТ]`. Проверить одним взглядом можно так:

```bash
grep -n "\[ИСПОЛНИТЕЛЬ\]\|\[ИНН\]\|\[ПОДДЕРЖКА\]\|\[БОТ\]" docs/legal/*.md
```

Если что-то нашлось — заполните `.env` и пересоберите документы:

```bash
.venv/bin/python scripts/render_legal.py
```

---

## 2. Публикация в Telegra.ph

1. Откройте <https://telegra.ph> → **New page**.
2. **Title** — название документа из таблицы выше (без слова «Редакция»).
3. Откройте файл в редакторе, выделите всё (Cmd+A), скопируйте (Cmd+C).
4. Вставьте в тело страницы (Cmd+V). Разметка сохранится: жирные заголовки,
   нумерованные пункты и списки.
5. Нажмите **Publish** и скопируйте полученную ссылку вида
   `https://telegra.ph/Politika-konfidencialnosti-10-06`.
6. Повторите для второго документа.

> Ссылка Telegra.ph не меняется при редактировании: когда обновите документ,
> откройте страницу → **Edit** → вставьте новый текст → **Publish**. Тот же URL
> продолжит работать, а банку не придётся получать новую ссылку.

---

## 3. Прописать ссылки в боте

В `.env`:

```ini
PRIVACY_URL=https://telegra.ph/...
TERMS_URL=https://telegra.ph/...
```

Затем перезапустить бота (если через Docker):

```bash
docker compose restart bot
```

Проверка: в боте раздел **«📄 Документы и цены»** — кнопки «🔒 Политика
конфиденциальности» и «📜 Пользовательское соглашение» открывают страницы.

Если ссылки ещё не прописаны, кнопки работают иначе: бот отдаёт полный текст
документа прямо в чате. Это сделано специально — документ должен быть доступен
клиенту **всегда**, даже до публикации.

---

## 4. Что отправить банку

Готовое письмо лежит в `docs/legal/ГОТОВНОСТЬ-К-БАНКУ.md` (раздел «Переписка
с банком») — остаётся подставить три ссылки:

1. Политика конфиденциальности — ссылка Telegra.ph.
2. Пользовательское соглашение — ссылка Telegra.ph.
3. Контакт поддержки — юзернейм из `SUPPORT_USERNAME` (группа не подходит,
   поэтому в документах указан личный контакт).
4. Цены и тарифы — тот же раздел в боте или ссылка на прайс.

Дополнительно можно показать, как документы выглядят для клиента: скриншот
раздела «📄 Документы и цены» в боте. Для банка это подтверждение, что документы
не спрятаны, а вынесены отдельными кнопками.

---

## 5. Если появится свой домен

Telegra.ph — быстрый путь. Когда будет домен и HTTPS, те же тексты можно
отдавать со своего сайта (`https://ваш-домен/legal/privacy` и
`/legal/terms`) — тогда достаточно поменять `PRIVACY_URL` и `TERMS_URL`
в `.env`, тексты останутся теми же: они собираются из `app/legal_texts.py`.

---

## 6. Обновление документов

Единственный источник правды — `app/legal_texts.py`. Порядок:

1. правите текст в `app/legal_texts.py`;
2. обновляете дату редакции в `.env` (`LEGAL_UPDATED_AT`);
3. выполняете `.venv/bin/python scripts/render_legal.py`;
4. обновляете страницы в Telegra.ph (Edit → вставить → Publish);
5. проверяете в боте, что текст совпадает с опубликованным.

Так политика в боте и на странице у банка не разойдутся — это первое, что
проверяют при повторной проверке.
