### КРИТИЧЕСКАЯ ПРОВЕРКА: заняты ли адреса AS34879 под аренду облачным провайдерам?

Проверено **эмпирически**: обратный DNS (`dig -x`) по **60 IP — по 6 адресов (.1/.30/.77/.150/.200/.250) в каждой
из 10 самых плотных белых /24** AS34879: `195.208.65.0/24`, `195.208.66.0/24`, `195.209.66.0/24`,
`195.209.87.0/24`, `195.209.88.0/24`, `195.209.89.0/24`, `195.209.90.0/24`, `212.193.146.0/24`,
`212.193.147.0/24`, `46.235.191.0/24`. Плюс `195.209.74.66` и `37.220.161.157`.

**Результат: 60 из 60 → `cdn.ngenix.net.`** (доп. два — тоже `cdn.ngenix.net`). Ни одного клиентского/хостерского PTR.

**Вывод:** 92.9 % белых /24 в AS34879 — это **собственные узлы CDN NGENIX**, а не пул под выдачу клиентам.
Гипотеза «AS34879 сдаёт адреса в аренду облачным провайдерам» **не подтвердилась в буквальном виде** — адреса
заняты собственной CDN-платформой. Но результат для задачи тот же: **розничной покупки VPS там нет вообще** —
нет продукта ВМ, только юрлица, IP не выдаются клиентам.
Высокая плотность белого списка здесь — **свойство CDN** (узлы CDN обязаны быть доступны из мобильных сетей,
иначе ломаются сайты за CDN), а не признак «удобного хостера». Это ловушка, а не возможность.

## КОРОТКИЙ ВЫВОД: есть ли розничная покупка VPS в этих подсетях?

**Из четырёх ASN розничная покупка VPS реально есть только у двух — EdgeCenter (AS210756) и DDoS-Guard (AS57724).**

1. **AS34879 — покупать нечего.** Это **NGENIX**, CDN-сеть в группе «Ростелеком – ЦОД», продающая защиту и ускорение
   сайтов **только юрлицам**. Продукта «виртуальный сервер» нет. Все 60 проверенных IP из 10 самых плотных белых /24
   — это `cdn.ngenix.net`, узлы CDN. **Его 92.9 % — не возможность, а артефакт**: CDN-узлы обязаны быть в белом списке,
   иначе недоступны сайты за CDN. Гипотеза «AS34879 сдаёт адреса облачным провайдерам» **не подтвердилась** —
   адреса заняты собственной CDN; но вывод для задачи тот же: **розницы нет вовсе**.
2. **AS201706 — покупать нечего.** ServicePipe — B2B-разработчик систем фильтрации трафика (в т.ч. для операторов
   связи). VPS/облачных серверов не продаёт; сайт закрыт 403 для всех, включая PDF.
3. **AS210756, EdgeCenter — единственный практичный кандидат**, но с тремя оговорками:
   (а) **прямой запрет «организации прокси-серверов» (п. 2.13 Правил использования услуг)** — то есть под VPN-задачу
   оферта формально нарушается; (б) обязательная **верификация через Госуслуги (ЕСИА)**; (в) **IP выдаётся случайным
   образом, выбрать подсеть нельзя** — при базовой доле 64.2 % попадание в белый /24 не гарантировано. Трафик —
   **безлимитный** (прямая цитата есть), минимум ≈ **1 697 ₽/мес без НДС**.
4. **AS57724, DDoS-Guard — VDS есть, трафик безлимитный**, но минимальная конфигурация **≈10 100 ₽/мес** из-за
   обязательного сетевого компонента (100 Мбит/с = 8 000 ₽), выбор/смена IP не подтверждены, заказ через лист
   ожидания, а **запрет VPN/прокси в AUP не найден** (что для задачи скорее плюс, но это «не найдено», а не «разрешено»).

**Практический смысл:** «доля белых /24» **не** является показателем пригодности хостера — она максимальна именно
у CDN (NGENIX 92.9 %), где VPS не купить. Из проверенных ASN **ни один не даёт одновременно**
(безлимит + возможность выбрать/сменить IP + отсутствие запрета прокси + розница для физлица).
