**Критично — утёкшие значения из `h1cloud-vless/main.sh` (публичный репозиторий):**

```

FORCED_UPDATE_URL   = https://my.h1cloud.net/api/vless/panel-main.sh   # владелец ноды сменить не может
DEFAULT_ROUTER_BASE = https://router.h1cloud.net
DEFAULT_ROUTER_TOKEN= 75c584ad7b0d975b69d4f86f36abd8bda092e41889076eb8   # ← зашитый токен TLS-роутера
XRAY_VERSION        = 26.3.27   # жёстко пинится; нода принудительно переустанавливает эту сборку
```

- Ноды **автоматически регистрируются** на центральном TLS-роутере → клиент получает доверенный
  `https://ROUTER/<slug>/sub/UUID`, при этом нода сама остаётся на обычном http.
- Версия Xray может быть переопределена **биллингом** через файл `xray_version.txt` (без правки скрипта) — вероятно, это и есть
  механизм кнопки **«поменять версию Xray»** в панели (`26627` в видео ≈ `26.3.27`).

**CLI ноды H1Cloud (из `vpn help`)** — полный набор, важнейшее выделено:

```
vpn add NAME DAYS [GB DEV]     # создать пользователя
vpn del/ban/unban/info/link/limit/logs/list/renew
vpn node NAME                  # имя локации для тегов ссылок
vpn tag ws|xhttp|reality VALUE
```
