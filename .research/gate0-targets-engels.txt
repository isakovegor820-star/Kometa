# Батч 3 — ЭНГЕЛЬС, по конкретным точкам (Лётка, Шурова гора)
#
# Почему отдельный батч. Владелец уточнил: «в Энгельсе не во всех локациях работает,
# например Лётка и Шурова гора». Это согласуется с механикой режима: он включается
# не по городу, а по конкретной вышке, поэтому один и тот же оператор в одном городе
# может давать разный результат в разных точках.
#
# Наш замер 14:02–14:07 сделан в Саратове (домашняя точка) и показал ОТСУТСТВИЕ фильтра.
# Этот батч нужен, чтобы поймать точку, ГДЕ ФИЛЬТР ЕСТЬ.
#
# ГЛАВНЫЙ ПРИЗНАК (не спутать):
#   * адреса ВНЕ списка (1.1.1.1, FI, NL, TimeWeb) начинают молчать или давать RST —
#     значит в ЭТОЙ точке режим включён;
#   * адреса В белом списке при этом ПРОХОДЯТ — значит вход существует и здесь.
#   Если же всё проходит так же, как в Саратове — в этой точке фильтра нет.
#
