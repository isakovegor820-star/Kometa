**Метод:** только открытые источники — сайты, оферты, документация API, базы знаний. Покупок, регистраций и оплат не производилось. Ряд API-эндпоинтов проверен фактическими запросами без авторизации (результаты приведены).

## Итог: у кого дешевле всего перебирать IP и почему

**1 место — 4VPS.** Единственный из пяти, у кого перебор адресов является **штатной документированной операцией с выбором подсети**:
- **5 бесплатных замен**, дальше 100 ₽ — то есть первые 5 попыток стоят **0 ₽** сверх аренды сервера.
- Система даёт **выбрать подсеть или конкретный адрес из списка** — это прямо отвечает на ключевой вопрос: **/24 меняется**, а не только последний октет.
- Полный **API управления IP**: `buyIp` (до 63 доп. IP на сервер), `iplist`, `deleteIp` — цикл «купить IP → проверить → удалить» автоматизируется целиком.
- **VPN назван целевым сценарием** на официальном сайте, прямого запрета в оферте нет (есть только отказ от гарантий работоспособности).
- **Риски:** цена минимума не подтверждена; «безлимит» в оферте не заявлен; п. 5.4.3 позволяет хостеру сменить ваш IP при нагрузке на канал; 5 бесплатных замен — вторичный источник.

**2 место — Timeweb Cloud.** Лучшая модель тарификации под перебор, но дороже вход:
- **Почасовое списание за IPv4** — можно заказать IP, проверить и удалить, заплатив за часы, а не за месяц.
- IP **отвязан от сервера** и живёт на аккаунте — не нужно пересоздавать VPS, чтобы получить/освободить адрес.
- Лимит **10 IP/сутки** на аккаунт — узкое место, но обходится обращением в поддержку.
- **Минусы:** нет выбора подсети; минимум **900 ₽/мес**; пересоздание сервера IP не меняет — менять надо именно публичный IP как отдельную сущность.

**3 место — Selectel VDS.** Инфраструктурно пригоден (почасовая оплата), но **прямо подтверждено, что пересоздание сервера сохраняет прежний IP**. Без штатной операции смены IP перебор через VDS невозможен. Точные методы API и цена не подтверждены.

**4 место — RUVDS.** Самый дешёвый вход (от 130 ₽/мес), но **худший для перебора**: замена IP как услуга **не предусмотрена вообще** (только «в крайнем случае»), подсеть выбрать нельзя. Плюс **п. 2.3.5**: приватный VPN разрешён лишь до **10 ГБ суммарного трафика в сутки**, публичный — запрещён. Для VPN-нагрузки это дисквалифицирующее ограничение.

**REG.RU** — оценить не удалось: весь сайт за анти-бот защитой.

## Что осталось неизвестным

1. **4VPS: первоисточник по смене IP.** Цифры «5 бесплатных замен / 100 ₽ / выбор подсети» взяты из отраслевой новости [pro-hosting.biz](https://pro-hosting.biz/news/companies/1516.html) от 17.09.2026. На самом 4vps.su и в вики (wiki.4vps.su) описания этой механики **нет** — вики содержит только инструкцию по правке IP внутри ОС. **Требуется подтверждение из ЛК/поддержки.**
2. **4VPS: цена минимальной конфигурации.** Цены рендерятся JS, `getTarifList` требует токена. Публично не получены.
3. **4VPS: безлимит трафика.** В оферте нет ни «безлимита», ни лимитов в ТБ/ГБ. Формулировка отсутствует — трактовать как безлимит нельзя.
4. **4VPS: цена доп. IP.** Есть только `"ip_price":"199"` из примера ответа API для локации «ОАЭ ДЦ1». Для РФ не подтверждено. Также неясно, списывается ли `ip_price` разово или ежемесячно.
5. **4VPS: доля попаданий по AS.** Не измерялась — без неё нельзя посчитать ожидаемое число попыток.
6. **Selectel: точные методы API управления IP.** `docs.selectel.ru/api/ip-addresses/` и `api/cloud-public-network/` есть в sitemap, но `.md`-версии отдают 404, а `api.vscale.io/v1/*` без токена отвечает HTTP 302. Имена методов (`/v1/scalets/…/ips`?) не подтверждены.
7. **Selectel: смена IP.** Подтверждено только, что **пересоздание** сервера сохраняет IP. Существует ли отдельная платная операция смены — не выяснено.
8. **Selectel: цена VDS 1-1-10** в ₽ — не получена.
9. **Selectel: трафик.** Явной формулировки о безлимите для VDS нет. PDF «Условия оказания услуг облачной платформы» (`selectel.ru/media/files/docs_ru/conditions-cloud-platform.pdf`) отдаёт **404**.
10. **Selectel: запрет прокси.** В Пользовательском соглашении **Vscale** — «не найдено» (0 вхождений VPN/прокси). Но это соглашение Vscale, а не актуальная оферта Selectel для VDS; последнюю прочитать не удалось.
11. **REG.RU: практически всё.** Сайт за анти-бот JS-челленджем (AjaxLoad), заглушка 13 602 байта. Не получены: смена IP и её цена, выбор подсети, API, трафик, запрет прокси, цена минимума. Также не проверено наличие API для реселлеров.
12. **Timeweb Cloud: оферта.** `/docs/legal` → 404; найден только `personal-data-policy.pdf`. **Запрет VPN/прокси — «не найдено»** (это не значит «разрешено»).
13. **Timeweb Cloud: точные имена методов API** управления IP не выверены по первоисточнику.
14. **НДС.** Ни для одного хостера не удалось однозначно установить, включён ли НДС в публичные цены.
15. **Аренда IP на час / посуточно.** Подтверждено только **почасовое списание за IPv4 у Timeweb Cloud** ([docs](https://timeweb.cloud/docs/public-ip)). Гипотеза об аренде IP «за 0,26 ₽/час» **не подтверждена ни у одного** из пяти хостеров. Посуточная аренда найдена только у RUVDS — и только для **Bare Metal** («от 661,5 ₽/день»), не для IP и не для VPS.
16. **Публичные сообщения 2026 года** о блокировке VPN/прокси или массовой смене пулов IP: **ничего не найдено** ни по одному из пяти хостеров, кроме косвенного — новая оферта 4VPS (ред. №3 от 19.08.2026) расширила раздел отказов от гарантий и добавила п. 5.4.3 о праве сменить IP клиента при нагрузке на канал.
