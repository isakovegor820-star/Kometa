# Безлимитный трафик на VPS + IP из «белых списков» мобильных операторов РФ

**Дата:** 09.10.2026 (Europe/Amsterdam). **Задача:** найти хостинги, которые дают **безлимитный трафик на VPS/VDS** и при этом имеют IP-адреса внутри «белых списков» мобильных операторов РФ (либо лояльную смену IP для перебора).
**Метод:** прямые GET-запросы к страницам тарифов и офертам (22 хоста + 11 CDN), `r.jina.ai` (markdown-рендер) для SPA/антибота, PDF-оферты (pdftotext), Discourse JSON API форума NTC (`/t/<id>.json`, 8 тредов, ≈700 постов), RIPEstat API (`announced-prefixes`) + пересечение с публичным CIDR-файлом белых списков (30 228 подсетей).

**Методика колонки «белых /24»** `[ПРОВЕРЕНО 2026-10-09]`: взят публичный файл `https://raw.githubusercontent.com/hxehex/russia-mobile-internet-whitelist/main/cidrwhitelist.txt` (30 228 подсетей, все ≤/24), развёрнут в набор /24 (141 664 шт.), затем пересечён с анонсированными префиксами ASN хостера (RIPEstat `announced-prefixes`, сегодня). «Белых /24» = сколько /24-единиц внутри анонсированного пространства хостера попадает внутрь записей белого списка. Это **не** то же самое, что цифры из `whitelist-entry.md` (там — снапшот `rewl` + живые IP): мои числа систематически выше и служат для **сравнения хостеров между собой**, а не как абсолют.
**Второе ограничение:** наличие «белой» /24 в AS хостера ≠ выдача VPS-адреса именно из неё. Ни один хостер не публикует, из какого пула выдаёт адреса конкретному продукту.

## 0. Короткий ответ

**«Безлимит + белые подсети» в одном флаконе существует — но не как товар, а как совпадение. Гарантированного «белого IP» не продаёт никто, и весь вопрос сводится к перебору.**

1. **Безлимитный трафик на VPS в РФ есть минимум у 10 хостеров** (§1), причём у части — с письменным подтверждением в оферте/FAQ, а не только в маркетинге. Самый дешёвый вход — **Selectel VDS 200 ₽/мес** (1 vCPU/0,5 ГБ/20 ГБ SSD, безлимит, 1 Гбит/с) `[ПРОВЕРЕНО 2026-10-09]`.
2. **У пяти хостеров с безлимитом в их же AS есть заметное пересечение с белым CIDR-файлом:** Selectel (258 /24), VK Cloud (529 /24), REG.RU (40 /24), Timeweb Cloud (64 /24), EuroByte/IHC (27 /24) — и это ровно те, где «безлимит + БС» формально сходится `[ОЦЕНКА по RIPEstat + CIDR-файл, 2026-10-09]`.
3. **Главный дефицит — не трафик, а адрес и лояльность.** Ни Selectel, ни VK Cloud, ни REG.RU, ни Timeweb **не дают выбрать IP** при создании; Selectel прямо пишет: «выделяется из пула адресов автоматически, **его нельзя выбрать**» `[ПРОВЕРЕНО 2026-10-09, docs.selectel.ru]`. Перебор = создание/удаление серверов или floating IP, что хостеры трактуют как злоупотребление (VK Cloud — документированные баны за перебор `[ЗАЯВЛ, NTC 24230]`).
4. **Лучшая «смена IP» — не у облаков, а у мелких хостеров:** 4VPS (5 бесплатных смен со сменой подсети + выбор конкретного IP за 100 ₽ + публичный API `buyIp`/`deleteIp`) `[ПРОВЕРЕНО 2026-10-09]` и Baxet (50 бесплатных смен, но с прямым отказом выдавать «белые» пулы) `[ИЗ КОРПУСА]`.
5. **Практические замеры корпуса отрицательные:** 19 адресов Selectel из ~17 подсетей — все не прошли (`rc=7`); 0 из 10 новых /24 EuroByte пересеклись с белым списком; VK Cloud отобрал адрес, аккаунт заблокирован за перебор `[ИЗ КОРПУСА + ЗАЯВЛ, NTC]`.
6. **CDN как «почти безлимит» дешевле, чем кажется:** 10 ТБ/мес — от **6 001 ₽** (Timeweb CDN, 0,6 ₽/ГБ) и **6 070 ₽** (Selectel CDN), **6 600 ₽** (VK Cloud CDN, 0,66 ₽/ГБ) против **12 000 ₽** у EdgeCenter Pro и CDNvideo (§3). Но именно CDN-платформы режут VPN-трафик автоматикой: Beget CDN (на платформе CDNvideo) заблокировал ресурс с формулировкой про «признаки трафика, похожего на VPN/proxy» `[ПРОВЕРЕНО 2026-10-09, NTC 25574, пост 7]`.
7. **Честный вывод:** «безлимит + белые списки» технически достижимо (Selectel VDS / REG.RU Cloud / Timeweb Cloud / VK Cloud), но **ни один продавец не гарантирует ни попадание, ни срок жизни адреса**, а регулятор целенаправленно демонтирует «эффект соседа» (Минцифры, 31.08.2026 — требование изолировать разрешённые IP в отдельные подсети `[ИЗ КОРПУСА, anti-malware.ru]`). Как продукт это не существует; как лотерея — 200–900 ₽/мес за билет.

### 2.2. Расчёт по трём лучшим

**(A) Selectel VDS — минимальная цена безлимита с крупнейшим белым пулом.**
- 200 ₽/мес (0,2976 ₽/час); безлимит и 1 Гбит/с — на всех ступенях `[ПРОВЕРЕНО 2026-10-09]`. Отдельной строки за публичный IP в прайсе VDS нет, а API создания сервера возвращает `public_address` → IP выдаётся вместе с сервером `[ОЦЕНКА на основе developers.vds.selectel.ru]`.
- При 100 клиентах × 30 ГБ = 3 ТБ/мес входа: **себестоимость трафика ≈ 0 ₽**, инфраструктура 200 ₽ → **2 ₽ на клиента** `[ОЦЕНКА]`. Это в 33–39 раз дешевле облачного egress (1,13–1,52 ₽/ГБ).
- Риск-цена: попадание в §2.12 (лимит 5–20 ТБ/мес на аккаунт) при «потенциально вредоносной активности» — то есть **безлимит есть ровно до того момента, как он станет заметен**.
- Механизм получения белого IP: только пересоздание серверов (в API VDS нет IP-методов) либо Selectel-облако + `selectel_roller` (28 IP/мин, но там плавающий IP 189,57 ₽/мес и **трафик облака платный**: в прайсе есть строка «Исходящий трафик вне инфраструктуры Selectel, свыше 10 ГБ в месяц, за 1 ГБ — **1,13 ₽**». Точная привязка этой строки к продукту «Облачные серверы» в прайсе не подписана — `[НЕ ПРОВЕРЕНО]`; если она применима, 3 ТБ ≈ 3 390 ₽/мес только за трафик, что убивает экономику) `[ПРОВЕРЕНО 2026-10-09, selectel.ru/prices/]`.
- Итог: **для «безлимитного релея» — да (200 ₽); для перебора — комбинировать с облаком нельзя дёшево.** Разумная схема: перебирать адрес в облаке (быстро, 28 IP/мин), а боевой релей держать на VDS.

**(B) REG.RU (Рег.облако) — безлимит письменно + плавающий IP по фиксированной цене.**
- 560,57 ₽/мес (1 vCPU/1 ГБ/10 ГБ NVMe) + 187,38 ₽/мес за плавающий публичный IP = **747,95 ₽/мес** `[ОЦЕНКА на основе reg.cloud, 2026-10-09]`.

- При 100 клиентах × 30 ГБ: **7,5 ₽ на клиента** `[ОЦЕНКА]`.
- Плюс: 40 белых /24 и «сервер из снэпшота получает новый IP» → механика перебора есть, хоть и медленная.

**(C) VK Cloud — если готовы рискнуть аккаунтом.**
- 529 белых /24 из 814 (65 %) — второе по плотности пространство в РФ после Yandex (535/858); безлимит 1 Гбит/с заявлен на продуктах Cloud Servers и VPS/VDS `[ПРОВЕРЕНО 2026-10-09]`.

**Выводы по CDN:**
1. **Самое дешёвое «почти 10 ТБ» — Timeweb (6 001 ₽), Selectel CDN (6 070 ₽), VK Cloud CDN (6 600 ₽)** — то есть **в 1,8–2 раза дешевле EdgeCenter Pro и CDNvideo** за тот же объём. Причём VK и Yandex **реселят тот же EdgeCenter**, только по 0,6–1 ₽/ГБ вместо 1,2 ₽/ГБ `[ПРОВЕРЕНО 2026-10-09, NTC 19123, пост 853; подтверждено калькуляторами]`.
2. **Плотность белого списка у CDN несопоставимо выше, чем у хостеров:** NGENIX 81,6 %, CDNvideo 67,7 %, EdgeCenter 63,3 %, VK 65 %, Yandex 62,4 % против 12 % у Selectel и 4,7 % у Timeweb. Для обхода БС CDN — «правильнее» по адресам (но это не гарантирует конкретный edge-IP).
3. **Главный риск — не цена, а автоматика против VPN.** Единственный документированный кейс — CDNvideo (платформа Beget, Selectel, Timeweb) отдаёт 403 на VPN/proxy-трафик. Timeweb у части участников NTC всё же заработал через GET+xhttp `[ПРОВЕРЕНО 2026-10-09, NTC 25574]`.
4. **Отдельная статья расходов, если нужен гарантированный статический адрес:** у Yandex Cloud CDN выделенная IP-адресация — **40 000 ₽/мес** `[ПРОВЕРЕНО 2026-10-09, docs]`. Это сразу выводит схему из бюджета.
5. Экономика: 10 ТБ/мес при 100 клиентах × 100 ГБ — это ровно тот масштаб, где CDN (6 000 ₽) уже дороже, чем безлимитный Selectel VDS (200 ₽) **в 30 раз**, если адрес удастся получить.

## 4. Что НЕ найдено (честно)

1. **Цены минимальных конфигураций:** VK Cloud, cloud.ru, Docker LTD, 4VPS VPS, SmartApe, vps.house, EdgeCenter VPS — рисуются JavaScript/конфигуратором, в HTML их нет. `[НЕ НАЙДЕНО]`
2. **Публичная политика смены IP** у Selectel VDS (кроме пересоздания сервера), VK Cloud, REG.RU (кроме цены плавающего IP), EuroByte/IHC, Docker LTD, EdgeCenter, Masterhost, SmartApe, ITSOFT, Filanco, StormNet. `[НЕ НАЙДЕНО]`
3. **Безлимит у 4VPS** — ни на странице VPS, ни в оферте условий по объёму трафика нет. `[НЕ НАЙДЕНО]` И при этом §5.4.3 оферты позволяет хостеру **в одностороннем порядке сменить ваш IP** при «большой нагрузке на интернет-канал».
4. **Публичные цены NGENIX, ServicePipe, DDoS-Guard CDN** — сайты либо блокируют (503/антибот), либо отдают 404 на страницах прайса. Публичного прайса в открытом доступе нет ни у одного из трёх. `[НЕ НАЙДЕНО]`
5. **Цены Gcore CDN** — `gcore.com/pricing/cdn` 404, на продуктовой странице цен нет. `[НЕ НАЙДЕНО]`
6. **Точный лимит пропускной способности Selectel floating IP** — документация отсылает к «таблице Пропускная способность», значение в HTML не отрендерилось. `[НЕ НАЙДЕНО]`
7. **AUP/fair-use REG.RU для облачных серверов** — FAQ утверждает «трафик неограничен», но оферту на предмет права ограничить скорость/объём я не читал. `[НЕ НАЙДЕНО]`
8. **Хостер, который ПРОДАЁТ «белый IP»** — не существует (подтверждено и предыдущим корпусом: никто публично не продаёт вход в белые списки; в январе 2026 РКН запретил облачным провайдерам сдавать такие адреса в аренду). `[ИЗ КОРПУСА + НЕ НАЙДЕНО сегодня]`
9. **Свежие (сентябрь–октябрь 2026) полевые замеры** «вот этот хостер + этот тариф дал белый IP» — на NTC не публикуются сознательно: «это непубличная информация, по очевидным причинам» (24230, пост 2).
