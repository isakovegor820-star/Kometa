# Kometa — VPN-сервис в Telegram

Бот продаёт подписку на защищённое подключение: тарифы, пробный доступ, оплата, автоматическая
выдача ключей и продление. Канал — витрина и поддержка.

> Полное описание продукта, экономика, риски и дорожная карта — в [ТЗ.md](ТЗ.md).

## Что уже работает

- 🤖 Telegram-бот (aiogram 3): главное меню, тарифы, пробный доступ, моя подписка, помощь, рефералка.
- 🎁 Пробный доступ: 3 дня / 1 устройство / безлимитный трафик, один раз на аккаунт.
- 💎 Тарифы: 1 мес — 199 ₽ (180 ⭐), 3 мес — 499 ₽ (450 ⭐), 6 мес — 890 ₽ (800 ⭐), 12 мес — 1 590 ₽ (1 420 ⭐).
- 🎉 **Рефералка и промокоды**: друг по персональной ссылке получает **скидку 50% на первую оплату**
  (+3 дня сверху), пригласивший — **+30 дней** после его оплаты. Скидка применяется автоматически,
  есть и промокод `KOMETA-XXXX` для ручного ввода. Награда не теряется, если у пригласившего ещё нет
  подписки: дни копятся и добавляются при первом подключении. Защита от накрутки: одна скидка на
  аккаунт, свой код не работает, не больше 10 наград в месяц. Владелец может создавать обычные
  промокоды (`/promo LAUNCH50 50 100 30`) — та же механика, свои процент, лимит и срок.
- 💳 Оплата: перевод по СБП с подтверждением админом, крипта (Crypto Pay), **Telegram Stars** — доступ включается сразу после оплаты.
- 🚧 **Пока оплата не подключена** (`SALES_ENABLED=false`): тарифы всё равно показаны кнопками с ценами,
  после выбора тарифа — кнопка «🟣 Оплата по СБП» и заглушка «оплата скоро будет доступна». Заказы не
  создаются, деньги не принимаются, но клиент и банк видят тарифы и путь оплаты целиком.
- 🏦 **WATA** (карты РФ и зарубежные, СБП, T-Pay, SberPay) — специализированный эквайринг для VPN-бизнеса,
  платёжная ссылка на заказ и вебхук с RSA-подписью. Включается строкой `WATA_TOKEN` в `.env`.
- 🤖 **Автоподтверждение переводов**: заказу выдаётся уникальная сумма (199.13 ₽) и код в комментарии,
  система сама читает выписку банка (CSV или почта по IMAP), находит платёж и выдаёт подписку без
  участия человека. Крипта подтверждается вебхуком Crypto Pay, звёзды — апдейтом Telegram.
  Несопоставленные поступления не теряются: админ получает уведомление.
- 🔗 Одна постоянная ссылка-подписка на все локации: `GET /sub/<token>`.
- 🛟 **Аварийные каналы в подписке**: ноде в админке ставится канал — «резервная» или «CDN»;
  каждая локация получает метку в имени, а подписка выносит канал отдельной группой автовыбора со
  **своим test-URL** (под ограничениями общий адрес замера недоступен, и клиент иначе считает
  профиль мёртвым). Клиенту — кнопка «Если не открывается» с честной инструкцией.
- 🔎 **Проверка готовности**: `python -m app.tools.emergency_check` показывает каналы, свежесть проб,
  пинг и отвечает ли `/ping` — и что именно мешает запуску (код возврата 1, если не готово).
- 🇷🇺 **РФ-сервисы напрямую**: в подписке Clash и sing-box есть правила для банков, Госуслуг,
  маркетплейсов и локальной сети — они идут мимо туннеля. Иначе банк просит «выключить VPN»,
  а на входном узле такой трафик выжигает адрес.
- ⏳ **Компенсация простоя**: `/downtime_start` открывает период, `/downtime_end` считает полные
  сутки (потолок 30) и продлевает активные подписки — один раз, повторная команда ничего не
  начислит; клиентам уходит сервисное сообщение. История и ручное начисление: `/downtime`,
  `/downtime_grant 3 причина`. Логика — `app/services/downtime.py`.
- 📶 **Проба нод и пинг**: каждые 5 минут TCP-проба до порта инбаунда (панель может отвечать, а
  порт клиента не пускать — это отдельный алерт `node_probe_failed`); задержка видна в админке и
  на странице подключения. `GET /ping` (204) используется как test-URL клиента, чтобы при сбоях
  связи приложение не помечало мёртвыми живые профили. Ручная проверка: `app.tools.ping_node`.
- 📡 Панель: абстракция `PanelClient` — 3x-ui в продакшене, встроенная заглушка для разработки.
- ⏰ Фоновые задачи: истечение подписок, напоминания за 3 и 1 день, авто-подтверждение крипты,
  закрытие просроченных заказов, мониторинг нод с алертами админам.
- 📊 Админка в боте: статистика, очередь заявок, выдача/продление/блокировка, рассылка, состояние нод.
  Команды по рефералке: `/referrals` (сводка и топ пригласивших), `/promos`, `/promo КОД ПРОЦЕНТ [активаций] [дней]`,
  `/promo_off КОД`, а в карточке `/user <tg_id>` видны приглашённые, заработанные дни и скидки в заказах.
- 🌐 **Веб-админ-панель `/admin`**: дашборд с выручкой и алертами, очередь заказов с массовым
  подтверждением, карточка клиента (подписка, заказы, события, заметки, метки), возвраты и ручные
  корректировки, финансы с CSV-выгрузками, ноды, журнал действий команды. Три роли — владелец,
  модератор, поддержка — с разными правами и аудитом каждого действия; вход по паролю
  `ADMIN_PANEL_PASSWORD` (резервный, владелец) или по учётной записи, сессия — подписанная cookie.
  Дизайн-система, сценарии модератора и макеты — в [docs/АДМИН-ПАНЕЛЬ.md](docs/АДМИН-ПАНЕЛЬ.md).
- 📄 **Раздел «Документы и цены»**: политика конфиденциальности, пользовательское соглашение, актуальные
  тарифы и контакт поддержки — отдельными кнопками в главном меню. Нужен для согласования с банком:
  документы должны быть доступны клиенту постоянно. Если ссылка на публикацию ещё не задана
  (`PRIVACY_URL` / `TERMS_URL`), бот отдаёт полный текст прямо в чате. Тексты — `app/legal_texts.py`,
  сборка для Telegra.ph — `.venv/bin/python scripts/render_legal.py`.
- 🧹 **Автопроверка формулировок** (`tests/test_public_texts_clean.py`): бот, страницы, заготовки постов,
  баннеры и документы не должны содержать формулировок, запрещённых платёжным партнёром, — сканер знает
  их и по-русски, и по-английски (дубли на других языках тоже под контролем).

## Быстрый старт (локально, без сервера)

```bash
cd "/Users/egor/Downloads/VPN servise"
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env      # вписать BOT_TOKEN и ADMIN_IDS
.venv/bin/python -m app.main
```

С `PANEL_TYPE=fake` бот полностью работает без VPN-сервера: создаёт «пользователей» в памяти,
выдаёт тестовые конфиги и позволяет пройти весь путь «пробный доступ → оплата → продление».

Запуск в фоне и остановка:

```bash
mkdir -p logs && (.venv/bin/python -m app.main > logs/bot.log 2>&1 &)   # запуск
tail -f logs/bot.log                                                    # логи
pkill -f "app.main"                                                     # остановка
```

Веб-слой подписки слушает `WEB_PORT` (по умолчанию 8090): `http://127.0.0.1:8090/health`.

## Проверка

```bash
.venv/bin/python -m pytest -q          # весь набор (686 тестов)
.venv/bin/python -m pytest tests/test_purchase_flow.py -q      # деньги: тариф → счёт → подтверждение
.venv/bin/python -m pytest tests/test_referral_promo.py -q     # рефералка и промокоды
.venv/bin/python -m pytest tests/test_finmodel_vps.py -q       # экономика связки «панель + ноды»
```

Экономика инфраструктуры считается кодом, а не на глаз:

```bash
.venv/bin/python -m app.tools.vps_costs                 # схемы, фонд замены нод, шкала клиентов
.venv/bin/python -m app.tools.vps_costs --users 100     # что покупать под 100 клиентов
.venv/bin/python -m app.tools.vps_costs --countries 5   # мультигео: сколько стоит 5 стран
.venv/bin/python -m app.tools.finmodel                  # выручка, отток, плато роста
.venv/bin/python scripts/build_remnawave_doc.py --check # документ про связку не разошёлся с моделью
```

## Структура

```
app/
  config.py            настройки из .env (pydantic-settings)
  main.py              запуск бота, планировщика и веб-слоя
  db/                  модели SQLAlchemy, сессии, справочник тарифов
  panels/              абстракция панели: base, fake, xui, registry
  payments/            абстракция оплаты: base, manual, cryptobot, stars, registry
  services/            подписки, заказы, рефералка, промокоды, уведомления, статистика, события
  bot/                 тексты, клавиатуры, middleware, фильтры, хендлеры
  web/sub.py           FastAPI: /sub/<token>, /health, /sub/<token>/info
scripts/               установка панели и нод, бэкапы, healthcheck
docs/                  инструкции по запуску и продажам
tests/                 pytest: ядро, веб-слой, панель, платежи
```

## Роли и правила

- Секреты — только в `.env` (в git не попадает). В коде токенов нет.
- Цены, лимиты, тексты — меняются без правки логики (БД + `app/bot/texts.py`).
- Панель и платёжки — за интерфейсами: замена 3x-ui или провайдера оплаты не трогает бота.
- Идемпотентность: повторное подтверждение заказа не продлевает подписку дважды.
